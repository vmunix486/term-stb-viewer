# tstbv

A little terminal image "printer" that uses `stb_image.h`.

I made this to learn how `stb_image.h` works, and to just use C a little more in general. I made this on my beloved Dell Latitude D610, while on a bus ride to a marching band competition (we won first place for the first time since 2008 btw)

Don't take my code as gospel, there's probably like a trillion security bugs, and segmentation faults ready to happen.
